# 成都农村产权交易所官网 - 产品需求文档（PRD）

## 1. 产品概述

本项目为成都农村产权交易所（成都农交所）全新品牌官网，参考原站点（`gzk94sa4qv1e.space.minimaxi.com`）的版式与内容架构，在此基础上进行全面视觉与体验升级，打造符合国家级农村产权交易场所气质的"高大上"门户。

- **核心目标**：以高端、权威、专业的视觉语言，传递交易所的公信力、科技感与农业根脉；为农村产权流转交易、粮油购销、国企采购、土地指标交易等核心业务提供权威信息发布与导流入口。
- **目标用户**：农村产权交易参与方（农户、村集体、涉农企业、国企采购方、金融机构）、政策研究者、媒体及社会公众。
- **市场价值**：强化"成都农交所"品牌资产，提升信息披露透明度与撮合效率，巩固其作为西南地区农村产权交易核心平台的行业地位。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 访问方式 | 核心权限 |
|------|---------------------|------------------|
| 公众访客 | 直接访问 | 浏览首页全部内容、新闻、政策、数据、跳转各业务平台 |
| 业务用户 | 注册跳转业务平台 | 经首页入口跳转至综合交易、粮油购销、国企采购、土地指标等子平台进行交易 |

> 本官网为门户展示型站点（无登录态），交易行为在跳转后的子平台完成。

### 2.2 功能模块

1. **首页（单页长滚动）**：顶部导航、Hero 主视觉、交易所简介、核心业务、数据中心、新闻中心、政策法规、合作伙伴、联系我们、页脚。
2. **业务平台跳转**：核心业务卡片提供至四个子平台的外链入口。

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 首页 | 顶部导航 | 品牌标识 + 主导航 + 语言/登录入口 + 滚动进度条；滚动时背景由透明渐变为毛玻璃实色 |
| 首页 | Hero 主视觉 | 全屏视觉：品牌中英文标题、副标语、双 CTA（了解更多 / 核心业务）、滚动指示；底部金融行情滚动条（滚动展示交易品类与价格指数），强化"交易所"气质 |
| 首页 | 交易所简介 | 左右分栏：左侧大字理念文案 + 关键资质标签（国家级试点、AAAAA 级交易所等），右侧数据卡片或配图 |
| 首页 | 核心业务 | 4 张大卡片：综合交易平台、粮油购销平台、国企采购平台、土地指标交易平台；每张含图标、名称、描述、在售项目数、跳转链接；hover 时卡片抬升、边缘流光 |
| 首页 | 数据中心 | 4 项核心指标（累计交易金额/项目数/服务面积/服务农户）滚动数字动画 + 月环比；下方双图：月度交易趋势折线图、交易类型分布环形图 |
| 首页 | 新闻中心 | 顶部 3 张大图轮播/特色新闻；下方 Tab（本所新闻 / 业界动态 / 通知公告）切换列表，每条含标题、日期、浏览数 |
| 首页 | 政策法规 | 国家级 / 省级 / 市级 三级标签筛选，卡片式列表展示政策标题、摘要、发布机构、日期 |
| 首页 | 合作伙伴 | Logo 墙滚动展示，体现生态背书 |
| 首页 | 联系我们 | 地址、电话、邮箱、工作时间 + 简易留言表单 |
| 首页 | 页脚 | 品牌信息、友情链接、备案号、版权、二维码、快速导航 |

## 3. 核心流程

访客打开网站 → Hero 区建立品牌认知 → 滚动浏览交易所简介与核心业务 → 在数据中心获得权威性背书 → 通过新闻/政策获取动态信息 → 通过业务卡片跳转至子平台完成交易；或通过页脚联系方式咨询。

## 4. 用户界面设计

### 4.1 设计风格

**美学方向：金融编辑感 × 农业根脉（Refined Editorial × Agrarian Roots）**

- **主色**：墨黑/深炭 `#0E1116`（深色区块基底，传递权威与稳重）
- **强调色**：磨砂金 `#C9A961`（财富、公信力、交易所气质）
- **辅助色**：苍翠绿 `#2D4A35`（农业根脉）、暖象牙 `#F5F0E6`（浅色区块、纸张感）
- **文字**：象牙白 `#F5F0E6`（深底）、墨黑 `#0E1116`（浅底）、金 `#C9A961`（点缀）
- **按钮风格**：金色描边按钮 + 实心金按钮两种；圆角极小（2-4px），克制方正，体现金融严谨
- **字体**：
  - 中文标题：`Noto Serif SC`（思源宋体，权威典雅）
  - 中文正文：`Noto Sans SC`（思源黑体，清晰现代）
  - 数据/数字：`JetBrains Mono` / `Space Mono`（等宽，行情屏感）
  - 英文小标签：`Cormorant Garamond`（衬线优雅，编辑感）
- **布局风格**：编辑杂志式、非对称、网格破格、留白克制；深浅区块交替制造节奏
- **图标**：`lucide-react` 线性图标，金色或象牙色
- **氛围细节**：细微颗粒噪点纹理、渐变网格、细金线分隔、行情滚动条、数字计数动画、滚动揭示

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|-----------|-------------|-------------|

| 首页 | 交易所简介 | 浅色象牙底，左侧大字理念 + 金色资质标签，右侧深色数据卡 |
| 首页 | 核心业务 | 深色底，2×2 大卡片，hover 抬升+流光边 |
| 首页 | 数据中心 | 深色底，4 个大数字（等宽字体计数动画）+ 双图表 |
| 首页 | 新闻中心 | 浅色底，顶部 3 特色卡片，下方 Tab 列表 |
| 首页 | 政策法规 | 浅色底，三级筛选 + 卡片列表 |
| 首页 | 合作伙伴 | 深色底，Logo 墙横向滚动 |

### 4.3 响应式

桌面优先（≥1280px 最佳），平板（768-1279px）与移动端（<768px）自适应：导航折叠为汉堡菜单、卡片单列、图表简化、字号缩放、行情条隐藏或简化。触控目标 ≥44px。

### 4.4 3D 场景

不适用（本项目以 2D 编辑式视觉为主，不使用 3D）。
