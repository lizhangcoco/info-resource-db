技术选型说明

🐍 后端技术

  • Python 3.8+ — 生态丰富，爬虫库成熟
  • Flask — 轻量级Web框架，简单灵活
  • SQLite — 嵌入式数据库，零配置
  • Requests + BeautifulSoup — 网页请求与解析
  • Click — 优雅的CLI命令行框架
  • Pydantic — 数据验证与模型定义

🎨 前端技术

  • HTML5 + CSS3 — 原生页面，无需构建
  • 原生 JavaScript (ES6+) — 不依赖框架，部署简单
  • ECharts — 强大的数据可视化图表库
  • 响应式设计 — 适配桌面端和移动端
  • Fetch API — 与后端异步通信

设计亮点

🔌
适配器模式
新增平台只需加一个采集器类
⚡
并发采集
多线程同时采集多个平台
📦
零配置部署
一条命令启动，开箱即用

💡 初始化数据示例说明

系统首次启动时，自动预置以下演示数据：

  • 3个关键词：iPhone 15 Pro、AirPods Pro、戴森吹风机
  • 每个关键词 30+ 商品：覆盖京东/淘宝/拼多多三大平台
  • 历史价格数据：每个商品有最近30天的价格波动记录
  • 完整的字段：名称、价格、销量、评分、店铺、链接等全部齐全
  • 打开网页即可看到完整的演示效果，无需等待采集
